# Jacquard

**Thesis.** Jacquard's punched cards were the first stored programs. His work is woven the same way: technologies are the warp, set up once and reused; each project is a pick across them. The site is his sample book.

**Palette.**
- Loom-state greige `#D7D8D3` (day ground)
- Charcoal warp `#1E2125` (day ink)
- Madder `#9B2D3B` / `#E06A74` (accent, Interface yarn)
- Indigo night `#0E1427` (night ground)
- Woad `#2E4380` / `#8FA5EA` (Language yarn)
- Weld `#94730F` / `#D8B44C` (Data yarn)

**Type.** Tenor Sans (display, museum-label caps), Hanken Grotesk (text), Chivo Mono (draft numbers, accession and selvedge lettering).

**Layout.** Name and a museum object label on the left; the cloth stacked over its weaving draft on the right, so the cloth reads as the draft's output.

**Signature.** A real weaving draft built from the data: 29 warp ends (technologies, threaded by kind), 9 weft picks (every project with a recorded stack), and a card chain where treadling would sit. Hover a pick or thread and the drawdown re-weaves: its ends take their yarn colour, shared ends light in other picks, a shuttle crosses the row.

**3D.** One canvas: loom-state cloth hanging from a rod, textured with the drawdown tiled 2 × 8 and a sewn name label. Pleats deepen toward the hem, the pointer sends a ripple through it, drag turns it, and hovering the draft re-dyes it. Renders only while moving. Swatches stay 2D: one object in space is enough, the draft is the content.

**Motion.** Stagger follows the weave, end by end and pick by pick. Nothing idles.

**Pages.**
- Projects: swatch book; each project a twill from its own pick, with selvedge label and catalogue entry.
- Experience: roles as threads over time; a thread carries on when a team moved (FastLane to Blai, Proghit to Zunta): 6 roles, 4 threads.
- Now/changelog: a loom log, one pick added per entry.
- Ask: a sampler board of pinned questions and answers.
- About: the full object label and a condition report.

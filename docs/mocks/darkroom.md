# Darkroom (Contact Sheet)

**Thesis.** A contact sheet is an honest record: every frame shot, a few marked. That fits a portfolio of 14 projects with 4 selects. The stock is invented: HALIDE TS·26 (TypeScript, 2026).

**Palette.** Safelight (dark): Safelight black #120605, Print paper #F3D6C2, Rebate #070303, Amber wax #FFB26B. Light table (light): Daylight #E8EDF0, Film base #E7A267, Negative ink #14181B, Red wax #C8101B. The dark theme shows positive contact prints; the light theme shows the same frames as orange-mask negatives on the table.

**Type.** Text: Schibsted Grotesk. Utility and edge print: Sofia Sans Extra Condensed (frame numbers, DX bars, stock name). Hand: Rock Salt, used only for grease-pencil tags.

**Layout.** Header, then a two-column hero: name and copy left, the developing tray right, with a full-bleed 35mm strip at the bottom carrying the real timeline (2022, 2024, 2026). Projects sit on a contact sheet (7 frames per strip on desktop, 3 on mobile), with DX-style edge codes (▸11, 11A). Selects get grease crop marks and a tag. The list below uses darkroom status words: Fixed (maintained), Developing (in progress), Sleeved (archived).

**Signature.** Developing. Every image fades up from blank paper, shadows first, both in the 3D tray and on each frame as it scrolls in. Hovering a frame or its row draws a grease-pencil ring around it.

**3D.** A procedural developer tray under the safelight, holding a print of roll 26. The print develops in a shader (dark tones reach density first). The liquid is a height field: pointer movement drops ripples that glint and refract the print, and dragging rocks the tray. Renders only while something moves; reduced motion gets the developed, still print. One scene only; the sheet stays DOM so frames remain readable links.

**Motion.** Slow chemical easing (about 1.8 s develops), quick 0.8 s pencil strokes.

**Pages.** Projects: the full 14-frame sheet, with a work print per project. Experience: a film strip roll, one frame per role, with dated edge codes. Now: the drying line, clipped prints of current work. Ask: questions as grease notes on sleeves. About: an enlargement with a written back.

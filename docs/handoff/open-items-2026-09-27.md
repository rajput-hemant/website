## Still-true context carried from the 2026-09-26 handoff

These points aren't in the cloud handoff. They were checked where noted; the rest is recorded as the owner said it.

**Checked against the code at `d1f38b1`:**

- Use `usePublicPathname()` (`lib/public-pathname.ts`), never raw `usePathname()`. Under rewrites the raw hook returns `/f/<id>/...` during static render, which caused React #418 hydration errors.
- tinykeys skips input fields by default; the shared shortcuts pass `{ ignore: () => false }` (`components/semantic/command/use-command-shortcuts.ts`).
- The Ask query uses `coalesce(slug.current, slug)` and filters out documents without a usable slug (`sanity/lib/queries.ts`). This keeps the build safe if the local `rebuild` branch writes its different ask model into the shared dataset again.
- e2e reuses a server on port 3020 and sets the `hr_flavor` cookie (`playwright.config.ts`).
- `site.handle` is `rajput-hemant` (`content/site.ts`).

**Checked against the code at `b50faeb` and now in `docs/flavors.md`:**

- Name rule: the header shows "Hemant Rajput"; the site UI elsewhere uses `rajput-hemant`. The resume, `<title>` and OG keep the real name. There is no JSON-LD in the code yet.
- Pre-paint theme scripts are raw `<script>` tags in each root layout's `<head>` (`components/semantic/prefs/pre-paint-script.tsx`), because `next/script` `beforeInteractive` runs late.
- Each edition's `cn()` is taught its custom text sizes (`flavors/<id>/lib/utils.ts`, on the `cn` package).
- `useSyncExternalStore` snapshots must be primitives, or React loops.
- The budget script strips `/f/<id>` to find a route's ceiling (`cleanRoute` in `scripts/check-budget.ts`).

**Recorded, not re-checked:**

- Writing: minimal comments; `bunx`, not `npx`.
- Asking: use pick-and-choose questions, not an HTML questionnaire. For design and interaction questions, research reference sites first and then decide.
- Quality bar: award-level, not generic. Green Core Web Vitals on a mid-range phone, fallbacks for no WebGL, reduced motion and low power, real DOM text and keyboard navigation.
- Owner's machine: `ls` is aliased to eza (use `command ls`); `cd` breaks `&&` chains through a zsh plugin, so use absolute paths or `git -C`. Playwright uses system Chrome via `PLAYWRIGHT_CHROMIUM_PATH`.
- Where the two handoffs disagree, the cloud handoff wins. For example, the 2026-09-26 handoff said "never push"; the cloud handoff says push only `portfolio-3d`. The owner set the cloud handoff's commit rules (`--no-gpg-sign --no-verify`, no trailers) aside on 2026-09-27; commits since then are signed and carry attribution trailers.
